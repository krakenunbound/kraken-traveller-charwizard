Thanks for going through the source so carefully. All four points are fixed in **1.0-beta2**:

1. **Connections no longer lowers other specialties.** With Electronics (computers) 4, a Connection in Electronics (sensors) now gives sensors 1 and leaves computers at 4. If a Connection would take the chosen skill above 3, or wouldn't add a level, it's refused and stays free for another pick.
2. & 3. **There's a new option, Options > Traveller Wizard > Rules printing:** *Core Rulebook (2016)* (the default, since that's what the SmiteWorks MGT2 module contains) or *Core Rulebook Update 2022*. The 2022 setting uses your values: University EDU 6+ entry, INT 6+ graduation, 10+ honours, and EDU +1 on graduation (on top of the +1 on entry). The academies use END 7+ / END 8+ / INT 8+ for entry and INT 7+ for graduation, and anagathics cost 1D x Cr25,000 a term. The buttons and texts change with the option, not just the data table.
4. **Closing the wizard no longer loses an unfinished Traveller.** Reopen it and carry on. A **Start over** button on the Characteristics page (click twice) begins a new one. The build still clears after Create Character or a reload of FGU.
